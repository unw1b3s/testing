# Практики 4–5. UI и формы

## Элементы интерфейса

| Элемент | Пример | Проверка |
|---|---|---|
| Текстовое поле | Почта, название задачи | Подпись, ввод, обязательность, границы |
| Password | Пароль | Маскировка, длина, неверное значение |
| Button | Войти, Добавить, Удалить | Доступность действия и результат |
| Select | Приоритет | Выбор и сохранение значения |
| Checkbox | Выполнена | Переключение состояния задачи |
| Radio | Все / Незавершённые | Фильтрация списка |
| Link | О приложении, справка | Навигация, новая вкладка |
| Alert | Подтверждение удаления | Подтверждение/отмена |
| iframe | Справка | Переключение контекста |
| Текст состояния | Сервис доступен | Обновление после ответа API |

Изучено описание фреймов в [официальной справке Figma](https://help.figma.com/hc/en-us/articles/360041539473-Frames-in-Figma-Design). В Figma макет обычно организован во фреймы, компоненты и стили; Inspect/Dev Mode позволяет смотреть размеры, отступы и цвета. Zeplin используется для передачи спецификаций разработчику. Для этой работы подготовлена локальная [схема экрана](login-wireframe.svg); аккаунт и сеанс Figma/Zeplin не использовались. Это ограничение практики 4.

В реализации: основная кнопка синяя, ошибки красные; подписи связаны с полями через `for`; основной размер текста 17 px; максимальная ширина контента 900 px; на узком экране отступы 16 px. Макет проверялся по фактическим снимкам приложения. Эталонного макета преподавателя нет, поэтому пиксельное соответствие внешнему макету не оценивалось.

## Обязательное задание №3. Авторизация

Итоговые результаты 27.10.2026, Selenium в Chrome. ОР и ФР сравниваются в `test_regression.py`, `test_smoke.py`.

| Ввод | Ожидаемый результат | Фактический результат |
|---|---|---|
| `student@example.com` / `Study123!` | Вход | PASS, список задач открыт |
| `other@example.com` / `Study123!` | Отказ | PASS, сообщение о неверных данных |
| `student@example.com` / `Wrong123!` | Отказ | PASS, сообщение о неверных данных |
| Пустая почта, правильный пароль | Блокировка формы | PASS, `valueMissing` у почты |
| Правильная почта, пустой пароль | Блокировка формы | PASS, `valueMissing` у пароля |
| `not-email` / `Study123!` | Блокировка формы | PASS, `typeMismatch` |
| Правильная почта / `1234567` | Блокировка формы | PASS, `tooShort` |
