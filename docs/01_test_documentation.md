# Практика 1. Тестовая документация

Объект: «Учебный планировщик», `http://127.0.0.1:8000/`.
Требования: вход по учебной учётной записи; задача 1–80 символов после удаления крайних пробелов; приоритет «Обычный» или «Высокий»; выполнение, фильтрация, удаление, выход. После перезагрузки задачи остаются в текущей сессии. После выхода сессия удаляется.

## Пять тест-кейсов

**TC-01. Успешный вход.** Приоритет: высокий. Предусловие: новый браузер, приложение запущено, вход не выполнен. Шаги: открыть `/`; ввести `student@example.com` и `Study123!`; нажать «Войти». ОР: виден заголовок «Мои задачи», форма входа скрыта, список пустой. ФР итогового прогона: соответствует, PASS. Автотест: `test_login_and_logout`.

**TC-02. Неверный пароль.** Приоритет: высокий. Предусловие: новый браузер на странице входа. Шаги: ввести `student@example.com`, `Wrong123!`; нажать «Войти». ОР: «Неверная почта или пароль», список задач не виден. ФР: соответствует, PASS. Автотест: `test_wrong_credentials[student@example.com-Wrong123!]`.

**TC-03. Пустая почта.** Приоритет: высокий. Предусловие: новый браузер на странице входа. Шаги: оставить почту пустой; ввести `Study123!`; нажать «Войти». ОР: браузер блокирует отправку, у почты `validity.valueMissing=true`, вход не выполнен. ФР: соответствует, PASS. Автотест: `test_login_validation[-Study123!-email-valueMissing]`.

**TC-04. Добавление задачи.** Приоритет: высокий. Предусловие: вход выполнен, список пустой. Шаги: ввести «Подготовить отчёт»; выбрать «Высокий»; нажать «Добавить»; обновить страницу. ОР: одна задача с этим названием и приоритетом, после обновления сохраняется. ФР: соответствует, PASS. Автотест: `test_create_task`.

**TC-05. Выполнение и удаление.** Приоритет: высокий. Предусловие: выполнен вход, добавлена задача «Прочитать конспект». Шаги: установить флажок; выбрать «Незавершённые»; выбрать «Все»; нажать «Удалить»; подтвердить диалог. ОР: выполненная задача скрывается первым фильтром, возвращается во «Все», после подтверждения удалена. ФР: соответствует, PASS. Автотест: `test_complete_and_delete`.

## Тест-сьют

`SUITE-SMOKE`: TC-01, TC-04, TC-05, открытие страницы, навигация. Пять отдельных тестов в `tests/test_smoke.py`, маркер `smoke`.
`SUITE-REGRESSION`: весь каталог `tests`, включая негативные UI-сценарии, API и вёрстку. Каждый тест получает новую браузерную сессию.
