# Баг-репорты

Дата: 27.10.2026. Окружение: macOS 27.0 arm64, Chrome 156.0.8078.48, Python 3.14.7. Оба дефекта обнаружены в первоначальном локальном приложении и исправлены до загрузки рабочей версии.

## BUG-01. Вход открывает JSON с ошибкой вместо списка задач

Severity: Critical. Priority: High. Статус: исправлен, перепроверен.

Предусловие: первоначальный `app.js`, новая сессия браузера.

Шаги:
1. Открыть главную страницу.
2. Ввести `student@example.com` / `Study123!`.
3. Нажать «Войти».

ОР: авторизация через POST `/api/login`, открытие списка задач.
ФР: обычная отправка формы через GET с параметрами почты и учебного пароля в URL; сервер возвращает 404 и JSON «Страница не найдена». В браузере синтаксическая ошибка `Unexpected end of input`.
Причина: отсутствовала закрывающая скобка обработчика удаления. Из-за ошибки весь файл JavaScript не выполнялся.
Исправление: закрыт обработчик `remove.onclick` в `app/static/app.js`.
Перепроверка: `node --check app/static/app.js` успешен; успешный и ошибочный вход проходят Selenium. В первом прогоне 10 падений из 24 были следствием этого дефекта; после исправления все 24 прошли.

Доказательства: [снимок падения](../evidence/bugs/BUG-01/login-failed.png), [исходный файл](../evidence/bugs/BUG-01/app.js.before.txt), [ошибка синтаксиса](../evidence/bugs/BUG-01/syntax.txt), [исходный JUnit](../evidence/local/pytest-initial.xml).

## BUG-02. Длинное название задачи расширяет страницу

Severity: Minor. Priority: Medium. Статус: исправлен, перепроверен.

Предусловие: версия CSS до переноса длинного текста, вход выполнен.

Шаги:
1. Добавить задачу с названием из 80 букв «Я» без пробелов.
2. В DevTools установить 320×568, затем 768×1024.
3. Проверить ширину документа и расположение кнопок.

ОР: название переносится; содержимое не выходит за ширину viewport.
ФР: при заданных 768 пикселях документ имел ширину 1099 пикселей. При мобильной эмуляции 320 пикселей содержимое расширяло видимую область до 895 пикселей, текст и элементы не помещались.
Причина: flex-элемент с длинным неделимым словом не мог сжиматься и переноситься.
Исправление: `min-width: 0`, `overflow-wrap: anywhere`; на узких экранах элементы задачи размещены сеткой.
Перепроверка: 320, 375, 768, 1280, 1920 пикселей — переполнения нет. Добавлены пять вариантов `test_long_title_layout`.

Доказательства: [снимок до исправления](../evidence/initial-layout/screenshots/viewport-768.png), [замеры до](../evidence/initial-layout/inspection.json), [замеры после](../evidence/inspection.json), [полная страница после](../evidence/screenshots/full-320.png).
