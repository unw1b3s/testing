# Практики 6–7. Матрица платформ и браузеров

Цель — проверить учебный сервис в настольном браузере и на узком экране. Статистики пользователей у нового приложения нет. Выбор основан на разных браузерных движках и доступном оборудовании; проценты аудитории не рассчитывались.

| ОС / среда | Браузер | Назначение | Фактический статус |
|---|---|---|---|
| macOS 27.0 arm64 | Chrome 156.0.8078.48, Blink | Локальный основной набор, адаптивность | 29 PASS |
| macOS 27.0 arm64 | Chrome Dev 158, Blink | Работа в DevTools | GET, заголовки и ответ просмотрены |
| Ubuntu, GitHub Actions | Chrome, Blink | Полный автоматический набор | См. [отчёт CI](09_results.md) |
| Ubuntu, GitHub Actions | Firefox, Gecko | Другой движок, полный набор | См. [отчёт CI](09_results.md) |
| Windows 11 | Edge / Chrome | План расширения для настольной Windows | Не выполнялось, окружения нет |
| macOS | Safari, WebKit | План расширения по движку WebKit | Полный набор не выполнялся |
| Android | Chrome | Проверка реального телефона | Не выполнялось; есть только эмуляция ширины |
| iOS | Safari | Реальное мобильное устройство и WebKit | Не выполнялось, устройства нет |

Для каждой комбинации запланированы вход/ошибка входа, создание и выполнение задачи, навигация, выход, длинное название. Наблюдать нужно также перенос текста, доступность кнопок и горизонтальную прокрутку. Размер viewport в DevTools не заменяет проверку сенсорного ввода, экранной клавиатуры и мобильной ОС.
